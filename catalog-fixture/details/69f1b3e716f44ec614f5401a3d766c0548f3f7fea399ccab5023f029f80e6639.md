Shows an activity you write yourself under your name, such as "Playing MaiCord", "Watching a film" or "Competing in a tournament". Fill in the settings; the activity is set a moment after you stop typing and is cleared when you turn the plugin off.

### Settings

- **Show this activity**: off by default, so nothing is shown until you turn it on.
- **Type**: Playing, Listening to, Watching or Competing in.
- **Name**, **Details**, **State**: the text of the activity, up to 128 bytes each. The name is required.
- **Timer**: none, or the time elapsed since you turned the activity on.
- **Application ID (optional)**: a Discord application id attached to the activity.

It can set your activity only, and connects to nothing.

Inspired by Vencord's CustomRPC plugin. Written from scratch for MaiCord; no Vencord code.
