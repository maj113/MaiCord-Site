Adds a button above the server list that marks every server as read in one click, clearing unread badges and mentions.

### Settings

- **Ask before marking everything read**: off by default. Turn it on to get a confirmation first.

It marks servers read through MaiCord itself, the same way "mark server as read" does for each one, one after the other. Direct messages are not touched.

Inspired by Vencord's ReadAllNotificationsButton plugin. Written from scratch for MaiCord; no Vencord code.
