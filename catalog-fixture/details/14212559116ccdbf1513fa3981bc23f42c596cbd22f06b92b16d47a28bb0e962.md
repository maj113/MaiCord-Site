Shows a speaker pill with the channel's name next to anyone who is in a voice channel. Hover it to read "In voice: General, My Server". On a profile it is a chip, "In General": click it to open that channel.

### Settings

- **Member list** and **On profiles**: on by default.
- **Next to message authors**: off by default.

The plugin reads the voice states MaiCord already tracks for the servers and calls you are in, so a user in a server you are not in does not show. It sends nothing, stores nothing and never joins a call for you.

Inspired by Vencord's UserVoiceShow plugin. Written from scratch for MaiCord; no Vencord code.
