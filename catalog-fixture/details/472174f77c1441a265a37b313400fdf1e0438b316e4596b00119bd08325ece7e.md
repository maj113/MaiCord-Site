Shows which devices a user is online on: Desktop, Mobile or Web. A user on several devices gets one badge that names them all ("Desktop+Mobile"), with the phone icon when they are on mobile. Offline users show nothing.

### Settings

- **Member list**, **Next to message authors** and **On profiles**: each is a switch, all on by default. On a profile each device is its own chip.
- **Hide when only on desktop**: off by default. Turn it on to see only the users who are on a phone or in a browser.
- **Colour by status**: on by default. Green is online, amber is idle and red is Do Not Disturb.

The plugin only reads the presence MaiCord already has. It sends nothing and stores nothing.

Inspired by Vencord's PlatformIndicators plugin. Written from scratch for MaiCord; no Vencord code.
