Why another client?

The official desktop app is a web page running in Electron, and it carries a whole browser with it. MaiCord renders on the GPU and only redraws when something on screen changes, so it starts instantly and sits idle at near-zero CPU. It is built in freestanding C++23 with no runtime dependencies beyond the DLLs that ship with Windows.

Features

MaiCord covers the Discord features you use every day, and more arrive with each release.

Chat

  • Markdown, code highlighting and ANSI colors
  • Embeds, galleries, stickers and custom emoji
  • Replies, forwards, pins, reactions, threads, forums and polls
  • Slash commands, app buttons, select menus and modals
  • Voice messages, an emoji, GIF and sticker picker, and file drag and drop
  • Search filters, mentions inbox and a Ctrl+K quick switcher

Voice and video

  • Voice channels with end-to-end encryption (DAVE)
  • Push-to-talk and per-user volume
  • Soundboard and stage channels
  • Watch Go Live streams and cameras, decoded on the GPU

Servers

  • Roles, permissions, members, bans and audit log
  • Emoji, stickers, soundboard and invites
  • Scheduled events and community onboarding
  • Per-server profiles and privacy settings

Accounts

  • Two-factor sign-in: security keys, Windows Hello, authenticator apps, SMS
  • QR code login
  • Up to five saved accounts with quick switching
  • Full profile editor with banners, decorations and effects

Built for Windows

  • Native notifications, tray icon and taskbar badge
  • Spellcheck and IME through Windows text services
  • Screen reader support through UI Automation
  • Signed automatic updates

Make it yours

  • Themes for colors, type, spacing and animated backgrounds
  • Dark, light and AMOLED bases
  • Native plugins with a stable C API
  • Plugin permissions you approve

Install

  1. Download MaiCord-{{version}}-windows-x64.zip ({{download_size}}) from the latest release.
  2. Extract it anywhere, for example %LOCALAPPDATA%\Programs\MaiCord.
  3. Run MaiCord.exe. No installer or admin rights are needed.

Requires Windows 10 or 11 (64-bit), a CPU with AVX and AES-NI, and a GPU with Direct3D 11 support.

FAQ

Is MaiCord free?

Yes. MaiCord is free and open source under the Mozilla Public License 2.0, and you can build it yourself from the source on GitHub.

Is it an official Discord app?

No. MaiCord is an unofficial third-party client, not affiliated with or endorsed by Discord Inc. Using third-party clients may violate Discord's Terms of Service and could put your account at risk. Use it at your own discretion.

Where are my sign-ins stored?

On your PC only, in %LOCALAPPDATA%\MaiCord, encrypted with Windows Data Protection so they can be read only by your Windows account.

How do updates work?

MaiCord checks GitHub for new releases and verifies each update against a signature built into the client before installing it.

Can I share my screen or camera?

Not yet. You can join voice, watch Go Live streams and see cameras today; sending video and screen share are on the roadmap.

Does it run on macOS or Linux?

No. MaiCord is built for Windows 10 and 11 and uses Direct3D 11 and other Windows APIs directly.
